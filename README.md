# Research & Development (R&D) Cell - PCCOE Pune

Official website for the Research & Development (R&D) Cell at Pimpri Chinchwad College of Engineering (PCCOE), Pune.

---

## 🌟 Highlights
- **100% Self-Contained**: Can be shared as a single `index.html` file or hosted on any static host (GitHub Pages, Vercel, Netlify). Loads completely offline with all photos, styles, and scripts bundled!
- **Minimalist High-Tech Aesthetics**: Sleek dark and light mode, glowing ambient gradients, and glassmorphism.
- **Council Members & Designations Directory**:
  - Live search by designation or wing.
  - Category filters (Executive Council, Domain Heads, Events & Operations).
  - Profile detail popup modal with contact links.
- **Institutional Sections**:
  - Research Thrust Areas (AI, Robotics, Clean Energy, IoT, Nanotechnology, Smart Cities).
  - Patents & Publications showcase.
  - Research proposal and collaboration inquiry form.

## 🚀 How to Host on GitHub & Launch Free Live Website (GitHub Pages)

### Option 1: Via GitHub Website (Easiest - No command line needed!)
1. Go to **[github.com](https://github.com)** and sign in.
2. Click the **`+`** icon in the top right and select **New repository**.
3. Name your repository (e.g. `rd-pccoe` or `rd-pccoe-website`).
4. Keep it **Public** and click **Create repository**.
5. On the next page, click **"uploading an existing file"**.
6. Drag and drop all the files from this folder (`index.html`, `members.html`, `assets`, `css`, `js`, `README.md`) into the GitHub upload area.
7. Click **Commit changes**.
8. Go to **Settings** > **Pages** (on the left menu).
9. Under **Branch**, select `main` (or `master`), select `/ (root)`, and click **Save**.
10. In 1–2 minutes, your website is live worldwide at:
    `https://<your-username>.github.io/<repo-name>/`!

5. Once published, go to your repository on GitHub > **Settings** > **Pages** > Select `main` branch > **Save**.

### Option 3: Using Git Command Line
```bash
git init
git add .
git commit -m "Initial commit of R&D PCCOE Website"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```
Then enable GitHub Pages in repository **Settings** > **Pages**.
